# Arabic Sub Fix — إضافة ترجمة عربية لـ Stremio

تجيب الترجمات العربية من OpenSubtitles وSubDL، وتصلح كل ملف قبل ما يوصل للتلفزيون:
- تحويل الترميز القديم (Windows-1256 / UTF-16) إلى UTF-8
- فك ملفات ZIP واختيار ملف الحلقة الصحيحة
- تحويل VTT إلى SRT نظيف وحذف أكواد مثل `{\an8}`
- ضبط اتجاه النص العربي وعلامات الترقيم

ما تحتاج أي مكتبات، بس **Node.js 18 أو أحدث**.

> مهم: Stremio يقبل الإضافات عبر رابط **HTTPS**. لذلك نشغّلها إما بنفق مؤقت من اللابتوب، أو على استضافة مجانية دائمة.
> تثبيت الإضافة مرة وحدة من الجوال أو اللابتوب يكفي، لأنها تنتقل تلقائيًا للتلفزيون عبر حسابك في Stremio.

---

## الطريقة 1: تجربة سريعة من اللابتوب (بدون GitHub)

1. ثبّت Node.js (نسخة LTS) من nodejs.org.
2. فك ضغط المجلد، وافتح Terminal أو CMD داخله، وشغّل:
   ```
   node server.js
   ```
3. ثبّت **cloudflared** من موقع Cloudflare، وفي نافذة ثانية شغّل:
   ```
   cloudflared tunnel --url http://localhost:7000
   ```
   بيعطيك رابط مثل `https://xxxx.trycloudflare.com`.
4. افتح الرابط من الجوال أو اللابتوب واضغط **تثبيت في Stremio**.

العيب: تشتغل بس واللابتوب شغّال، والرابط يتغير كل مرة (يعني تعيد التثبيت).

## الطريقة 2: تشغيل دائم ومجاني (عن طريق GitHub + Render)

1. ارفع ملفات المجلد على مستودع جديد في GitHub.
2. سجّل في render.com بحساب GitHub، واختر **New → Web Service** واختر المستودع.
3. الإعدادات:
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: Free
4. (اختياري) في **Environment** أضف `SUBDL_API_KEY` بمفتاحك من subdl.com.
5. بعد ما يخلص، افتح الرابط اللي يعطيك إياه Render واضغط **تثبيت في Stremio**.

ملاحظة: الخطة المجانية تنام بعد فترة بدون استخدام، فأول مرة تفتح قائمة الترجمة ممكن تتأخر أو تطلع فاضية. سكّر القائمة وافتحها بعد دقيقة.

## الإعدادات (متغيرات اختيارية)

| المتغير | الوظيفة | الافتراضي |
|---|---|---|
| `SUBDL_API_KEY` | تفعيل مصدر SubDL (مفتاح مجاني من subdl.com) | غير مفعّل |
| `MAX_PER_SOURCE` | أقصى عدد ترجمات من كل مصدر | 20 |
| `FIX_RTL` | ضع `0` لإيقاف تعديل اتجاه النص | مفعّل |
| `PUBLIC_URL` | الرابط العام إذا الروابط طلعت غلط | تلقائي |
| `PORT` | المنفذ | 7000 |

## الاستخدام في التلفزيون

شغّل الحلقة ← الترجمة ← العربية ← اختر الترجمات اللي تحت اسم **Arabic Sub Fix**.
